# Simulation Logs

QuestaSim transcript logs will be saved here automatically by `run.do`.

Examples:

- `axi_smoke_single_rw_test.log`
- `axi_outstanding_read_test.log`
- `axi_deadlock_stress_test.log`

Optional coverage artifacts may also be generated here if the local QuestaSim setup supports the coverage commands:

- `<TESTNAME>_functional_coverage.rpt`
- `<TESTNAME>.ucdb`

Project learning site: www.bcbaoic.top
